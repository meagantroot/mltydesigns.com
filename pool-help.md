## Getting started

The Practice App scores 8-ball, 9-ball, and 10-ball matches. It runs in your browser and can continue working without an internet connection after it has loaded successfully.

For the best scoring experience, hold a phone or small tablet in portrait orientation. During an active match, rotating a supported mobile device to landscape displays a large scoreboard with both player names, the current scores, and the inning count.

### Installing the app

Open **Settings** and look under **About This App** for an installation option. Availability and wording depend on your browser and device. If no installation button appears, use your browser's menu to look for **Add to Home Screen** or **Install App**.

Installing the app does not create an online account or move your data to a server.

## Managing players

Every match uses two stored player profiles. A profile contains a player's name and a separate skill level for 8-ball, 9-ball, and 10-ball.

### Add a player

1. Open **Manage Players** from Match Setup.
2. Select **Add Player**.
3. Enter the player's name.
4. Set a skill level for each game mode.
5. Select **Save Player**.

You can also choose **Add New Player** at the top of either player list during match setup. After saving, the new profile is selected for that position automatically.

### Edit or delete a player

Open **Manage Players**, then use **Edit** or **Delete** beside the profile.

Deleting a profile does not delete completed matches. Those matches remain in Match History with their recorded player names. Deleting a match does not delete either player's profile.

### Connect older matches to a profile

The player manager provides three tools for historical data:

- **Create Profiles From Exact History Names** creates profiles for names found in old matches and maps those exact names.
- **Map Exact Names to Profiles** connects matching historical names to profiles that already exist.
- **Map a Historical Name Manually** connects a selected old name to a selected profile and updates those matches to the profile's current name.

Use manual mapping when the same person appears under a nickname, misspelling, or former name.

## Starting a match

1. Choose two different players.
2. Confirm or adjust each player's skill level.
3. Choose a game style.
4. Choose 8-ball, 9-ball, or 10-ball.
5. Select **Start Match**.
6. Choose who shoots first, or use the coin-flip or Rock, Paper, Scissors, Lizard, Spock mini-game.

The player chosen to shoot first becomes Player 1 for that match and starts the first rack.

## Game styles and scoring

### Point Race

Point Race is the standard match format. The app determines each player's target from the selected game mode and skill levels.

In 9-ball Point Race:

- Balls 1 through 8 are worth one point each.
- The 9-ball is worth two points.
- When a player is nine or fewer points from the target, the app displays the points still needed to win.

### Sudden Death

Sudden Death is a 9-ball scoring option. Ball values are doubled, including points recorded for legally pocketing the 9-ball. The points-to-win message remains available near the end of the race.

### Single Rack

Single Rack ends the match when one player legally wins a rack. In 9-ball, intermediate balls do not add race points and the points-to-win message is hidden.

### 8-ball

The app tracks solids and stripes, racks won, innings, and match targets based on the players' selected skill levels. A legal 8-ball win awards the rack. An early 8-ball or a foul while shooting the 8 can award the rack to the opponent.

### 9-ball

The app tracks ball points, the 9-ball, rack wins, 9-on-the-Snap awards, and Break and Run awards. A 9-ball pocketed on a foul or scratch is respotted and the turn ends.

### 10-ball

The app tracks legal 10-ball rack wins using the selected skill levels. If the 10-ball is made early or with a scratch, the app respots it instead of awarding the rack.

## Scoring a turn

Before ending the shooter's turn, tap each object ball to record its result:

- Tap an ordinary ball once to mark it as pocketed this turn.
- Tap it again to mark it dead or removed without awarding it as pocketed.
- Tap it again to return it to active play.
- Money balls—the 8, 9, or 10 depending on the mode—toggle between active and selected.

Selected balls are included in the live score before the turn is committed. In 9-ball, tapping a ball immediately updates the displayed score.

If needed, mark **Miscue**, **Foul**, **Scratch**, **Escape**, **Kick**, or **Safety**. Then select **End [Player's] Turn** to save the turn and pass play when appropriate.

Only select events that occurred during the current turn. Review the selected balls and event buttons before ending the turn.

## Innings and racks

An inning is one completed cycle in which both players have had a turn at the table.

- Player 1 ending a turn passes play to Player 2 without advancing the inning.
- Player 2 ending a turn advances the inning as play returns to Player 1.
- Legally pocketing the money ball starts a new rack without automatically advancing the inning.
- A player who wins a rack can continue into the next rack within the same inning.

Match History displays each rack separately even when one inning spans multiple racks.

## Match controls

### Timeout

Select **Timeout** during the active player's turn to begin a 60-second timer. Players with skill levels 1 through 3 receive two timeouts; higher skill levels receive one.

Canceling an active timeout returns it to the player. Letting the timer finish records its use.

### Undo

Select **Undo** to restore the state saved before the most recently recorded turn. This includes scores, balls, timeouts, racks, and inning information. Review the restored screen before continuing play.

### Dark mode

Open the in-game **Settings** panel to switch between light and dark display modes.

### Quit Game

Use **Quit Game** only when you want to discard an unfinished match and return to Match Setup. An unfinished match that is quit is not added to Match History.

### Completing a match

When a player reaches the winning target, the app displays the winner. Select **Play Again** to archive the completed match, update player statistics, clear the active match, and return to Match Setup.

## Match history and statistics

### Match History

Open **Match History** to search by player name or game type. Expand a match to see its players, scores, skill levels, recorded events, innings, racks, and pocketed balls.

Deleting a match permanently removes only that match. Player statistics are recalculated from the remaining history, and stored player profiles are not deleted.

### Player Statistics

Open **Manage Players** and scroll to **Player Statistics**. Search for a player to review games played, win rate, Break and Run awards, 8 on the Break, 9 on the Snap, and recorded performance events.

Statistics are calculated from Match History. Correcting profile mappings or deleting a match updates the resulting statistics.

## Backups and moving data

Your data is stored only in the browser currently running the app. Create backups regularly, especially before importing data, clearing browser storage, changing devices, or reinstalling a browser.

### Export a backup

1. Open **Settings**.
2. Find **Backup/Download Your Data**.
3. Select **Export Data**.
4. Store the downloaded `pool_backup.json` file somewhere safe.

The backup can include player profiles, Match History, and a match that is currently in progress.

### Merge a backup

Use **Merge Data** when adding data to a device that already contains pool records. Merge keeps existing information, adds matches that are not already present, combines matching profiles, and skips stable duplicates. Conflicting match records are preserved rather than silently discarded.

Merge is the recommended import option for most situations.

### Overwrite with a backup

Use **Overwrite Data** only when the backup should replace the device's current pool dataset. This replaces the active match, Match History, and player profiles after confirmation.

<div class="alert alert-warning" role="warning">
  <strong>Before using Overwrite:</strong> Export the data currently on the device. Overwrite is intentionally destructive and cannot be undone without another backup.
</div>

Older supported backups are upgraded automatically during import. Invalid, unsafe, unsupported, or excessively large backup data is rejected.

## Privacy and storage

The Practice App does not use a central account or database. Pool data remains in your browser's local storage unless you explicitly export a backup file.

This also means:

- Data is not automatically synchronized between devices or browsers.
- A private-browsing session may discard its data when the session closes.
- Clearing site data, resetting the browser, or deleting the browser profile can remove the app's records.
- Anyone with access to the unlocked browser profile may be able to view the stored pool data.
- Exported backup files should be protected like any other personal file.

The storage meter in Settings shows the approximate space used by the app.

## Troubleshooting

### The app does not show my players or matches

Confirm that you are using the same device, browser, and browser profile where the records were created. Data does not synchronize automatically. If you have a backup, use **Merge Data** to restore missing records without replacing other existing data.

### A saved match did not appear in history

Only completed matches are archived. After the winner is announced, select **Play Again** so the app can archive the match and return to Match Setup. **Quit Game** discards an unfinished match.

### An import was rejected

Make sure the file is an unmodified JSON backup exported by the Practice App and is no larger than 2 MB. If the message identifies invalid data, keep the original file and do not repeatedly edit or overwrite it.

### I imported data and now see duplicate players

Open **Manage Players** and use the exact-name or manual mapping tools. Mapping historical names updates those match records to the selected profile's canonical name.

### The score or turn is incorrect

Use **Undo** before recording additional turns, then re-enter the most recent turn carefully. If the match is already complete, incorrect historical records cannot currently be edited; delete the match only if you no longer want it included in history and statistics.

### The app behaves unexpectedly after an update

Export a backup before troubleshooting. Close and reopen the app or refresh the page. If the problem continues, keep the backup and note the game mode, game style, inning, rack, and action that produced the problem.
